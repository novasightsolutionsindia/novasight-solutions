# NovaSight Solutions - Complete Website

A professional, responsive website for NovaSight Solutions, a CCTV and security solutions business in Hanumangarh, Rajasthan.

## 📋 Project Overview

This is a complete, production-ready website with:
- Modern, responsive frontend
- Full admin panel
- Online booking system
- Customer management
- Service management
- Interactive Google Map
- No database required (uses localStorage)

## 🎯 Features

### Public Website
- ✅ Modern, responsive design with navy blue (#0a2647) and cyan (#00b4d8) theme
- ✅ Dynamic content loading from JSON/localStorage
- ✅ Services showcase with icons
- ✅ Satisfied customers list
- ✅ Google rating display (4.9 ★)
- ✅ Online booking form with validation
- ✅ Interactive Leaflet map with exact location
- ✅ Contact information with WhatsApp integration
- ✅ Mobile-friendly navigation

### Admin Panel
- ✅ Secure login system
- ✅ Dashboard with statistics
- ✅ Manage services (Add/Edit/Delete)
- ✅ Manage customers (Add/Edit/Delete)
- ✅ View and manage bookings
- ✅ Update business settings
- ✅ All data stored in browser's localStorage
